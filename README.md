# HockeyCoach – pracovní prezentační web

Statický vícestránkový web. Nejde o aplikaci ani kompletní ověřenou dokumentaci.
Všechny ukázky jsou ilustrační a obsahují výhradně fiktivní údaje.
Původní screenshoty nejsou přibalené.

## Nahrání na GitHub
1. Rozbalte ZIP v počítači.
2. V repozitáři otevřete Add file → Upload files.
3. Přetáhněte OBSAH rozbalené složky, včetně složky assets.
4. index.html musí být přímo v kořeni repozitáře.
5. Uložte přes Commit changes.
6. Settings → Pages → Deploy from a branch → main → / (root) → Save.
7. Adresu nasazeného webu převezměte ze Settings → Pages.

Před přepsáním existujícího webu si uschovejte původní soubory.
Načítají se jen místní CSS a JS. Instalace balíčků není potřeba.

## Soubory
index.html: úvod
funkce.html: přehled oblastí
ukazky.html: modelové tabulky
role.html: navržené členění podle rolí
navod.html: rozpracované kapitoly
o-projektu.html: stav projektu a ochrana údajů
assets/style.css: společný vzhled
assets/script.js: mobilní menu

## Úpravy
Texty měňte v příslušných HTML souborech. Společné barvy a vzhled v assets/style.css.
Menu a patička jsou ve všech stránkách; při změně navigace upravte každou stránku.
Před publikací přesné funkce, logo a oprávnění ověřte ve zdrojovém kódu aplikace.
